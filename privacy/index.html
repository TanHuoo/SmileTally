1. 适用范围与联系方式

本政策说明喜脉（以下简称“我们”）在提供 Smile Tally 随口算 iOS 应用及本官网时，如何处理与你有关的信息。我们提供日常计算辅助，无需在 App 内注册账号；App Store 购买仍可能需要使用你的 Apple 账户。

运营与联系：喜脉；邮箱：ximai@88.com；微信：we1ye2。

2. 处理哪些信息，为什么处理

计算文字、条件及相关对话

你正式发送的问题、补充条件、修改内容及相关历史上下文，会用于理解问题、生成计算计划和解释结果。输入中可能包含你自行提供的金额、工时或其他个人信息；请只提供完成计算所需的内容。上述信息会在云端计算时交由我们的服务及 DeepSeek 处理。

主动选择的图片

App 通过系统照片选择器读取你选中的图片，不扫描整个相册。图片会在本机生成用于预览与计算的副本；正式发送后才随请求上传至计算服务及 DeepSeek，用于识别价格、规格等信息。请在发送前遮盖与计算无关的姓名、地址、订单号等内容。

语音与转写

只有你开始语音输入时才使用麦克风和 Apple 语音识别。支持时优先在设备上转写；不支持时可能由 Apple 在线处理音频。App 不将原始录音作为历史文件保存，也不把原始录音发送给 DeepSeek。转写先进入草稿，点击发送后，转写文字才按计算文字处理。

本机历史及偏好

会话、计算结果、关联图片副本和必要的待处理请求状态保存在 App 本机存储；震动等偏好保存在设备上。继续追问时，相关历史会作为上下文参与计算。我们未提供独立的跨设备历史云同步；iOS 设备备份是否包含应用数据，取决于系统设置和备份机制。

匿名安装标识、额度与请求状态

App 在系统钥匙串保存随机安装凭据；服务端使用其摘要及必要的请求标识、时间、处理状态、返回结果和每日用量，管理额度、防止重复扣次并恢复请求。无注册账号不代表完全匿名：这些记录可以关联同一安装或购买权益。返回结果可能包含你提供的计算条件或由图片提取的信息。

购买与客服信息

支付由 Apple 处理。为验证、恢复会员权益及计算付费额度，我们处理商品标识、交易标识和交易验证结果，不获取你的完整银行卡信息或 Apple 账户密码。你主动联系时，我们会处理你的联系地址、问题描述及所附材料，用于回复和处理请求。

3. 第三方服务与共享

我们不出售个人信息，不在 App 内使用广告追踪 SDK，也不为跨应用广告追踪读取广告标识符。为提供功能，以下服务会参与处理：

  • DeepSeek（深度求索）：接收正式发送的文字、相关上下文、条件和所选图片，用于问题理解、图片识别、计算计划及解释。我们不会把 Apple 支付凭据或原始语音作为计算内容发送给 DeepSeek。其公开政策说明了服务数据处理及可能的模型优化用途，本服务不承诺第三方“零留存”或“绝不用于训练”。有关第三方数据权利请求，可先联系我们协助处理。参见 DeepSeek 隐私政策。
  • Apple：提供系统语音识别、App Store 支付及购买验证。所处理信息包括识别所需音频（使用在线识别时）及交易信息。参见 Apple 隐私政策。
  • GitHub Pages：托管本官网。访问官网时，GitHub 会为安全目的记录 IP 地址，并可能处理必要的访问技术信息。参见 GitHub 隐私声明。

我们仅为所述目的提供必要数据，并依法要求受托处理方履行相应的数据保护义务。依法必须披露，或为保护用户合法权益、处理安全事件确有必要时，我们会按适用法律处理。除此以外的新增用途或共享，我们会另行说明并在依法需要时取得授权。

4. 保存位置、期限与保护

本机数据保存在你的设备上，历史和相关图片副本保留至你主动删除；未发送草稿不会因预览而上传至计算服务。系统钥匙串与系统备份可能独立保留数据，卸载 App 不等于删除所有钥匙串、备份或服务端记录。

计算服务记录用于额度核对、失败返还、请求恢复及购买验证。目前请求结果、用量和购买关联记录没有按固定天数自动删除；你可以按下一节申请处理。我们会依据提供服务、处理争议及法定义务所必需的期限判断保留范围，在目的完成且无需继续保留时删除或匿名化。图片原始内容不写入我们的请求结果数据库，但识别出的文字或数字可能存在于结果中。

云端计算意味着数据离开设备。DeepSeek 公开政策说明其在中华人民共和国境内存储相关服务数据；Apple、GitHub 等服务可能依据其政策在不同国家或地区处理信息。我们不承诺所有信息都只在本机或同一地区处理；如我们开展依法需单独告知或同意的跨境提供，会履行相应要求。

我们通过加密传输、系统访问保护及必要的访问限制保护数据。请同时保护设备与邮箱账号，避免提交与计算无关的敏感信息。发生影响个人信息安全的事件时，我们会按适用法律处理并履行通知义务。

5. 你的隐私选择与权利

  • 查看、更正与复制：在 App 中查看历史、复制结果，通过修改条件重新计算；也可联系邮箱提出访问、复制或更正请求。
  • 删除本机记录：在历史列表左滑删除，或在设置中选择“清除全部历史”。关联的本机图片副本会随历史删除，系统相册原图不受影响。删除单张方案卡只是筛除展示项，不等于删除完整历史或原始数据。
  • 申请删除服务端数据：发送邮件至 ximai@88.com，说明请求及大致使用时间。我们会只索取核实关联关系所必需的信息，在适用法律期限内处理；因无注册账号，可能需要你配合核实，无法准确关联时会向你说明。法定必须保留或处理交易争议所需的记录会说明保留原因。本机清除不会自动清除服务端或第三方记录。
  • 撤回权限或停止提供：在 iOS 设置中关闭麦克风、语音识别等权限；仍可使用不依赖该权限的功能。不发送问题或图片可停止新增云端计算内容，但不自动删除已合法处理的信息。
  • 无账号注销流程：本 App 不提供注册账号，故无 App 内账号可注销。数据删除与 Apple 订阅取消是两件事；如需停止续费，请在系统订阅设置中另行取消。

如对数据处理有异议，或希望限制、反对某项处理，请通过上述邮箱联系。我们会核实并回复处理结果；你依法享有向主管机构投诉的权利。

6. 官网与联系渠道

本官网是静态信息网站，不要求登录，不提供在线计算或文件上传，不设置广告 Cookie、访客追踪脚本、分析 SDK 或站外字体请求。托管方的必要访问记录见第三方服务说明。

点击邮箱会打开你选择的邮件工具，不会在网页上直接发送信息。使用微信或邮件联系时，相应服务提供商会依据其政策处理通信内容；我们仅使用你主动提供的信息跟进咨询。

7. 未成年人

本产品不专门面向儿童。未成年人应在监护人指导下使用和理解数据处理规则，不应提交不必要的敏感信息。需要监护人同意的情形，应先取得相应同意。监护人如发现儿童个人信息被不当提交，可联系我们核实、删除或采取其他保护措施。

8. 政策更新

功能或数据处理方式发生变化时，我们会更新本页日期与内容；影响你的重要权利或依法需要重新授权的变化，会通过适当方式提示并取得必要同意。你可随时通过技术支持页联系我们。

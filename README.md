## 维护与部署

纯 HTML/CSS，无构建依赖、无登录、无统计脚本、无外部字体。四个页面无需 JavaScript 即可阅读；FAQ 使用原生 details，联系方式为 mailto 链接。

GitHub Pages 发布来源：main 分支根目录。推送后自动部署，.nojekyll 让静态文件直接发布。所有站内资源和导航支持 /SmileTally/ 项目路径。

本地预览：

```sh
python3 -m http.server 8765
```

打开 http://localhost:8765/ 。修改 HTML 或 CSS 后刷新。

assets/logo.svg 复用产品品牌图形；首页对话为 HTML/CSS 功能示意，不是在线计算器或 App 实际截图。

本仓库仅存放公开网站。不得加入 App / 服务端源码、内部资料、用户记录、证书或密钥。公开联系方式已经运营者确认。

产品数据处理或订阅规则变化时，同步更新政策、协议及生效日期；App Store Connect 资料与 App 内声明需保持一致。
